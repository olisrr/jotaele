# Jota Ele · web

Web del Restaurante Jota Ele (Plaza de Santa Isabel, 6 · Murcia) en HTML plano.

- **Vista previa para revisar:** https://nebularmedia.github.io/jotaele/ (opción A) y https://nebularmedia.github.io/jotaele/b/ (opción B). No sale en Google.
- **Web real:** se sube el contenido de esta carpeta (sin `.git`, `.github` ni este README) a `public_html` en SiteGround. El `.htaccess` es para SiteGround.
- Cada push a `main` actualiza la vista previa.
